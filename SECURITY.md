# Security Policy

## Reporting security issues

If you discover a security issue in this repository, please report it privately to D2MA Limited through the contact method listed at https://d2ma.com.

Do not open public issues containing secrets, personal medical information, credentials, tokens, or exploitable vulnerabilities.

## Sensitive data

This repository should never contain real patient data or secrets. If such data is found, remove it from the public tree and history before release.


## Hosted deployments

If you deploy Spine Harmony or a derivative as a hosted service that accepts real medical data, obtain legal, privacy, regulatory, clinical safety, and security review first. A hosted medical-data workflow is materially different from publishing an open-source template repository.
