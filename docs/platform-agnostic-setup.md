# Platform-Agnostic Setup

Spine Harmony can be adapted to any agent runtime that supports persistent instructions, workspace files, and tool use.

Minimum requirements:

- a private workspace directory;
- project instructions from `AGENTS.md`;
- user profile from `templates/USER.md`;
- journal/timeline file from `templates/SpineHarmony_Journal.md`;
- strict exclusion of private data from version control.
